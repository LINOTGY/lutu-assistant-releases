# 率土助手安装说明

适用系统：Windows 10/11 64 位。安装包已包含 Python 和程序依赖，玩家无需安装 Python。

## 首次安装

1. 将收到的 ZIP 解压到普通文件夹。ZIP 内有 `率土助手_免Python安装_Setup.exe`、本说明和 `SHA256SUMS.txt`。
2. 双击 `率土助手_免Python安装_Setup.exe`，按向导安装。可使用默认安装位置，也可选择其他磁盘。
3. 按 Windows 键，搜索“率土助手”，点击开始菜单中的程序。

安装后即可查看和查询本机已保存的战报。首次使用没有战报时，需要通过自动采集取得。自动采集需要 MuMu 模拟器、开启 Root，并运行当前已验证的游戏 9.2.8；可在软件的“MuMu 采集设置”中自动查找或指定模拟器位置。其他模拟器或游戏版本尚未验证。

## 更新软件

打开软件侧栏的“软件更新”。软件已预填发布仓库 `https://github.com/LINOTGY/lutu-assistant-releases`，会从它的 GitHub Releases 检查正式版。发现新版本后点击“下载并校验安装包”，等待 SHA-256 校验通过，再点击“打开安装包文件夹”。**先关闭率土助手，再双击下载的 Setup.exe 覆盖安装。**也可以直接从发布者处获取新版 Setup.exe 覆盖安装。

GitHub 暂时无法访问时，不影响本机已有战报的查看和查询。

## 数据和卸载

程序默认安装在 `%LOCALAPPDATA%\Programs\率土助手`，若安装时选择其他目录则以所选目录为准。战报、设置和备份保存在 `%LOCALAPPDATA%\率土助手\data`。覆盖安装和卸载程序不会删除这个数据目录；需要迁移到新电脑时，请单独备份该目录。

`SHA256SUMS.txt` 列出安装程序的 SHA-256，可用于核对传输后的文件是否完整。分发 ZIP 不含任何玩家战报、账号或采集数据。

旧开发版数据仅在项目 `local_app\data` 时，可关闭软件后运行：

```cmd
"%LOCALAPPDATA%\Programs\率土助手\率土助手.exe" --migrate-data "C:\你的项目\local_app\data"
```

如果安装版已有实际战报或设置，迁移会拒绝覆盖。
